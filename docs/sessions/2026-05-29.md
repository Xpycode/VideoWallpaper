### Goal
Make the three main-window sections (Displays, Video Sources, Playlist) draggable/reorderable, and fix the Playlist section which was not collapsible.

### Completed
- [x] **Playlist section now collapsible**: Refactored `PlaylistSection.swift` to wrap content in `CollapsibleSection` (storage key `playlistSectionExpanded`). Previously marked "non-collapsible" in comments.
- [x] **Drag handles on all section headers**: Added `dragProvider: (() -> NSItemProvider)?` parameter to `CollapsibleSection`. When non-nil, a `⁝⁝⁝` gripper icon appears on the left of the header, visible on hover only.
- [x] **Section reordering via drag-drop**: Rewrote `MainWindowView` with:
  - `SectionKind` enum (displays, sources, playlist)
  - Order persisted in `UserDefaults` key `mainWindowSectionOrder` as JSON
  - `SectionDropDelegate` handles real-time reorder on `dropEntered`, saves on `performDrop`
  - `UTType.plainText` item providers carry section IDs
- [x] Threaded `dragProvider` through `DisplaysSectionView` and `SourcesSectionView` as an optional parameter (default nil, no breaking change)
- [x] Build green ✓, app launched and verified

### Decisions Made
- Drag initiates only from the grip icon (not the full header) to avoid conflicts with the collapse button tap and interactive header controls
- Grip icon fades in on hover to keep the header clean when not in use
- `maxHeight: .infinity` moved inside PlaylistSection's CollapsibleSection content so it only expands when the section is open
