### Decisions Made

- Transport controls stay visible in Displays header even when section is collapsed
- Per-display settings (scaling/transition/speed/playlist) become a ⚙ popover on each display tile
- Advanced Settings → standard macOS `cmd+,` Settings window (free from `Settings {}` scene)
- `DisclosureGroup` explicitly avoided — custom `CollapsibleSection` with instant content toggle
- `PlaylistTabBar.swift` reused as-is for both display tabs and playlist tabs
- `ConsolidatedPlaylistView`: lift `selectedScreenId` out as a binding (only significant surgery)
- Min window size: 480×400 (down from 650px — sidebar gone)
